# Project Profile

Living notes about *this specific project* — the user's preferences
and working style as observed in this folder, the kind of work that
happens here, the conventions you've adopted, the recurring people /
places / files that matter. Project-local memory, not a user dossier;
different projects get different profiles.

Starts empty. The harness pipes this file into your system prompt
on every turn, so anything written here is in your working memory.
Update it via `write_file` per the `profile-maintenance` policy:
concrete observations, not labels; pruned when stale; never bloated.
